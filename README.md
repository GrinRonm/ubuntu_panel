**Ubuntu Panel (ServerDeck)** — ультралёгкая, современная и полнофункциональная веб-панель управления сервером для **Ubuntu** и **Debian**. 

Разработана как быстрая и чистая альтернатива громоздким системам (*Cockpit, aaPanel, Webmin*). В отличие от них, панель упакована в компактный Docker-контейнер, взаимодействует с хостом через `nsenter`, не засоряет операционную систему тяжелыми зависимостями, не меняет ваши существующие конфиги Nginx и потребляет всего **~50 МБ оперативной памяти**.

---

## 🚀 Установка в 1 команду

Для установки панели на чистый или уже работающий сервер (Ubuntu 20.04 / 22.04 / 24.04 или Debian 11 / 12) выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/GrinRonm/ubuntu_panel/main/install.sh | bash
```

*Или через `wget`:*
```bash
wget -qO- https://raw.githubusercontent.com/GrinRonm/ubuntu_panel/main/install.sh | bash
```

Скрипт автоматически:
1. Проверит и установит Docker и Docker Compose (если они ещё не установлены).
2. Загрузит проект в `/opt/ubuntu_panel`.
3. Сгенерирует безопасные ключи и учетные данные администратора.
4. Соберет и запустит контейнер в фоновом режиме.
5. Настроит системный фаервол UFW для доступа к порту `8088`.
6. Выведет URL панели и данные для входа.

## 💡 Архитектура и Производительность

- **Минимальный оверхед**: потребление памяти составляет всего **50-55 МБ RAM** (в 10-20 раз меньше аналогов).
- **Прямой контроль хоста**: благодаря правам `privileged` и маппингу пространств имен ядра через `nsenter`, панель управляет `systemd`, `ufw`, `samba`, `vsftpd`, `crontab` и `nginx` напрямую на физическом сервере.
- **Мгновенная отзывчивость**:
  - Асинхронный бэкенд на **FastAPI** с поддержкой **Gzip-сжатия**.
  - Веб-сокеты для живых метрик без задержек.
  - Кольцевой буфер истории в **SQLite WAL Mode**.
  - Кэширование опроса дисков и служб — нагрузка на CPU в режиме ожидания составляет **<0.5%**, что идеально подходит даже для самых слабых VPS (1 vCPU, 512MB RAM).

## 🛠 Возможности

### 📊 1. Дашборд реального времени
- Живые графики нагрузки CPU, ядер, RAM, Swap, дисковых накопителей и скорости сетевых интерфейсов.
- История метрик за последние 15 минут, 1 час, 6 часов и 24 часа.

### 🌐 2. Nginx Сайты & Прокси-менеджер
- Просмотр всех конфигураций из `sites-available` и `sites-enabled`.
- Мастер добавления сайтов (Reverse Proxy для веб-приложений или статический сайт / PHP-FPM).
- Встроенный подсветчик синтаксиса, валидация конфигурации (`nginx -t`) и безопасная перезагрузка.

### 🔒 3. SSL / Let's Encrypt
- Выпуск и продление бесплатных SSL-сертификатов через Certbot.
- Автоматическая привязка HTTPS (порт 443 + HTTP/2) к сайтам Nginx.

### 📁 4. Сетевые папки Samba (SMB / CIFS)
- Полное управление общими папками в `/etc/samba/smb.conf`.
- Копирование Windows UNC-пути в один клик (`\\SERVER_IP\ShareName`).
- Настройка прав (Чтение/Запись, Гостевой доступ, Скрытая/Видимая папка, списки `valid users`).
- Управление базой пользователей Samba (`pdbedit` / `smbpasswd`).
- Просмотр активных подключений в реальном времени (`smbstatus`).
- Встроенная проверка `testparm` перед сохранением.

### 📡 5. FTP Сервер (vsftpd)
- Управление службой `vsftpd` (старт, стоп, перезапуск).
- Быстрое переключение `write_enable`, `chroot_local_user` (изоляция пользователей), `anonymous_enable`.
- Настройка диапазона пассивных портов (PASV) и автоматическое открытие в UFW.
- Управление FTP-пользователями и их корневыми папками.
- **Встроенный интерактивный тестер подключения**: проверка доступности, баннера и авторизации прямо из браузера.

### ⚙️ 6. Службы & Автозапуск (systemd)
- Мониторинг всех системных сервисов.
- **Управление автозапуском при загрузке системы**: переключение статуса `Enabled` / `Disabled` в один клик (`systemctl enable/disable`).
- Вкладка быстрой фильтрации: *Все*, *Запущенные*, *В автозапуске*, *Избранные*.
- Просмотр логов любой службы в реальном времени через `journalctl`.

### 🐳 7. Docker Контейнеры
- Просмотр запущенных и остановленных контейнеров, используемых образов и проброшенных портов.
- Запуск, остановка и перезапуск контейнеров в один клик.

### 🛡 8. Сеть & Фаервол (UFW & Сканер портов)
- Сканер прослушиваемых локальных портов (TCP/UDP) с указанием процесса (PID).
- Управление правилами UFW: добавление разрешений по порту или подсети, удаление правил, включение/выключение фаервола.

### 💾 9. S.M.A.R.T. Здоровье накопителей
- Чтение температуры, атрибутов износа и общего состояния HDD / NVMe / SSD через `smartctl`.
- Запуск быстрых и полных тестов самодиагностики накопителей.

### ⏰ 10. Планировщик задач (Cron)
- Просмотр и редактирование задач пользователя в `crontab`.
- Быстрое включение / пауза задач без удаления.
- Кнопка ручного запуска задачи «Прямо сейчас» с выводом stdout/stderr и замером времени выполнения.

### 📂 11. Файловый менеджер
- Удобная навигация по файловой системе хоста.
- Загрузка файлов с компьютера, скачивание, создание папок и файлов.
- Встроенный редактор текстовых файлов и конфигураций.

### 👥 12. Пользователи сервера
- Список системных учетных записей.
- Создание новых пользователей, управление правами `sudo`, смена паролей.

### 💻 13. Интерактивный Web-терминал
- Полнофункциональный эмулятор терминала **xterm.js** прямо в браузере.
- Полноценная поддержка PTY, цветов ANSI, горячих клавиш (Ctrl+C, Tab и т.д.) и динамического изменения размера окна.

## 📦 Ручная установка через Docker Compose

Если вы предпочитаете настраивать всё вручную:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/GrinRonm/ubuntu_panel.git /opt/ubuntu_panel
   cd /opt/ubuntu_panel
   ```

2. Создайте файл окружения `.env`:
   ```bash
   ADMIN_USER=admin
   ADMIN_PASS=ВашСложныйПароль
   SECRET_KEY=СлучайныйСекретныйКлюч
   PORT=8088
   ```

3. Запустите контейнер:
   ```bash
   docker compose up -d --build
   ```

4. Откройте в браузере: `http://<IP_СЕРВЕРА>:8088/`

## 🔒 Безопасность и Рекомендации

- Рекомендуется закрыть прямой доступ к порту 8088 из внешнего интернета и настроить проксирование через Nginx с SSL-сертификатом:
  ```nginx
  server {
      listen 443 ssl http2;
      server_name panel.yourdomain.com;

      ssl_certificate /etc/letsencrypt/live/panel.yourdomain.com/fullchain.pem;
      ssl_certificate_key /etc/letsencrypt/live/panel.yourdomain.com/privkey.pem;

      location / {
          proxy_pass http://127.0.0.1:8088;
          proxy_http_version 1.1;
          proxy_set_header Upgrade $http_upgrade;
          proxy_set_header Connection "upgrade";
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
      }
  }
  ```
